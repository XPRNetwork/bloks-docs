# Anchor

Anchor is a security and privacy focused open-source digital wallet for all Antelope-based networks including XPR Network, FIO and WAX blockchains.

This wallet is useful if you are an advanced user or developer and want to login to the explorer using your (owner) key permission.

## LOGIN TO [EXPLORER](https://explorer.xprnetwork.org/) USING ANCHOR

### 1. Download and install Anchor [here](https://www.greymass.com/anchor).

<figure><img src="../../.gitbook/assets/image (3).png" alt=""><figcaption></figcaption></figure>

Make sure the app stays active and the window is open while you interact with the [explorer](https://explorer.xprnetwork.org/).&#x20;

### 2. Go to Explorer, Click Login at the top right corner.

<figure><img src="../../.gitbook/assets/image_login_initial.png" alt=""><figcaption></figcaption></figure>

### 3. Select Anchor in the Connect To Wallet pop up window.&#x20;

<figure><img src="../../.gitbook/assets/image (135) (1).png" alt=""><figcaption></figcaption></figure>

### 4. Anchor will show you QR code to scan with mobile application.

<figure><img src="../../.gitbook/assets/image (83) (1).png" alt=""><figcaption></figcaption></figure>

### 5. Confirm that you are successfully logged in.

![](<../../.gitbook/assets/image (202).png>)

You should see your account username in the top right corner if you have successfully logged in.
