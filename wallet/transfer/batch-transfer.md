# Batch transfer

## HOW TO TRANSFER TOKENS TO MULTIPLE ACCOUNTS

### Go to Wallet → Transfer tokens page

### Switch to Batch transfer tab in top menu of the page

<figure><img src="../../.gitbook/assets/image_wallet_batch_transfer_00.png" alt=""><figcaption></figcaption></figure>

### Prepare CSV file using the example on the page and upload it

<figure><img src="../../.gitbook/assets/image_wallet_batch_transfer_01.png" alt=""><figcaption></figcaption></figure>

The template for CSV is the following: `to, amount, token, contract, memo`

### Check the results table

<figure><img src="../../.gitbook/assets/image_wallet_batch_transfer_02.png" alt=""><figcaption></figcaption></figure>

### Click Transfer button

<figure><img src="../../.gitbook/assets/image_wallet_batch_transfer_03.png" alt=""><figcaption></figcaption></figure>
